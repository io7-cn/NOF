# Security reporting

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/io7-cn/NOF/security/advisories/new).
Include affected versions, a minimal reproduction, impact and any mitigation.
Do not publish exploit details, credentials or customer data in a public issue.
If private reporting is unavailable, use a private contact channel listed on the
[maintainer's profile](https://github.com/XmmShp) to arrange confidential reporting.

The repository maintainers coordinate triage, fixes, affected releases and
disclosure with the reporter. See the [development standards](docs/en/README.md)
and [开发规范](docs/zh-CN/README.md) for the review and delivery requirements.
