# Security reporting

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/io7-cn/NOF/security/advisories/new). Include affected versions, a minimal reproduction, impact and mitigation. Do not publish exploit details, credentials or customer data in public issues.

See the [English security guide](docs/en/security.md) or [Simplified Chinese guide](docs/zh-CN/security.md) for confidential fallback contact and coordinated disclosure.
