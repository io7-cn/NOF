# API reference

[简体中文](../zh-CN/api-reference.md)

The [generated reference](../api/index.md) is built from public library XML comments and the Release assemblies. Namespaces/type names remain the published CLR identifiers; generated member descriptions follow the source language. Use the [package guides](packages/index.md) and [architecture guides](design/index.md) for English or Simplified Chinese explanations and complete composition examples.

Build the owning projects before generating metadata. Source-generator packages retain compiler-compatible targets; runtime libraries use the pinned .NET SDK. Generated api output and the rendered site are build artifacts, not a second handwritten API specification.
