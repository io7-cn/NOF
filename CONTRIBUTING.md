# Contributing to NOF

Read the maintained [English contributor guide](docs/en/contributing.md) or [Simplified Chinese guide](docs/zh-CN/contributing.md) before changing code or documentation. Use an issue-linked topic branch, preserve unrelated work and submit a pull request to main. Seek independent local review and pass the required technical checks before merge.

The repository follows its exact pinned [development standards](docs/en/README.md).
